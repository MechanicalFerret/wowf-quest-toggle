# Quest Toggle

Quest Toggle adds a **Toggle All** button to the bottom right of the map's quest log. One click tracks or untracks every quest at once. Each zone header in the quest log also gets a small **T** button that does the same for only that zone's quests. It is made for World of Warcraft Forever.

- If any quest is tracked, all quests are untracked.
- If no quests are tracked, every quest in your log is tracked, up to the game's tracking limit.
- `/qt` or `/questtoggle` does the same as the button.

## Installation

### WoWUp
1. Open WoWUp and select the World of Warcraft Forever client.
2. Go to **Get Addons** and click **Install from URL**.
3. Paste `https://github.com/MechanicalFerret/wowf-quest-toggle` and click **Install**.

WoWUp will then update the addon for you when a new release is published.

### Manual
1. Download the latest zip from the [Releases](https://github.com/MechanicalFerret/wowf-quest-toggle/releases) page.
2. Extract it so the folder is named `QuestToggle` and sits inside `World of Warcraft/_forever_/Interface/AddOns`.
3. Restart the game, or run `/reload` if it is already open.

# Quest Toggle

A World of Warcraft addon that adds a **Toggle All** button to the bottom right of the map's quest log. One click tracks or untracks every quest at once. Each zone category header also gets a small **T** button that does the same for only that category's quests.

- If any quest is currently tracked, all quests are untracked.
- If none are tracked, every quest in your log is tracked, up to the game's tracking limit.
- `/qt` or `/questtoggle` does the same thing without the button.

## Installation

Copy the `QuestToggle` folder (keep that folder name, it must match the `.toc`) into your `Interface/AddOns` directory and run `/reload`.
